# Daily self-check and informative task

User asks to reconstruct the game to infer crew mental status and add recurring home-screen mood/discomfort reports, redirecting negative reports to Self-check. Implement an exploratory attention-change signal, not a psychiatric classifier. Clinical inference cannot be validated by game implementation alone.

Evidence: NASA Reaction Self Test project https://techport.nasa.gov/projects/23201 and primary astronaut study https://pmc.ncbi.nlm.nih.gov/articles/PMC8919197/ . The study used a validated 3-minute PVT-B plus subjective scales, not this prototype's short task. Its in-flight schedule was every fourth day. Our 20-hour reminder is a product/demo setting, not NASA protocol.

Daily entry: explicit 1–5 mood choice and comfortable/uncomfortable choice; no defaults. Save in current run, dated by mission and real UTC clocks. Mood <=2 or discomfort opens Self-check with separately displayed local context (not copied into exported notes), requiring explicit symptom submission. No existing symptom is cleared by a comfortable report. Home card is due initially or 20 hours after the latest eligible report, using real elapsed time or advancing mission time (whichever reaches the interval first). Minute refresh while open; reload recomputes offline. Non-blocking; no OS notification permission. Demo Advance 20 hours makes due behavior reviewable.

Signal Watch replaces pair matching: optional practice and 12-signal recorded round; randomized waits, response/missed and premature-input logging; consistent selected input mode. End/background/mission-replay change cancels without a saved assessment. Store completed results locally with protocol/input mode, trial data, dates and rule version. Compare against at least three prior eligible saved rounds using the same input and protocol in this browser. Insufficient responses/baseline => insufficient evidence. A >25% AND >75ms median slowdown, two extra misses, or three extra early inputs versus baseline are illustrative prototype flags only. No disease, emotional label, flight-fitness judgment, or automatic medical escalation.

Keep old mood entries compatible; keep optional mood question. Local History shows daily and task records with reasons/baseline. Ground packets continue excluding local wellbeing data; explain shared-tablet visibility. Show exact limits and sources in task explanation.

Verify deterministic reminder boundaries and analysis against no baseline, misses, incompatible input, future data and stable records; browser exercise practice/completion/cancel/save/retry, daily routing, refresh/offline persistence, 20-hour demo boundary, narrow layouts and existing crew/cloud/report workflows. Independent review before publish under configured user author identity.
